# Checklist - GeoPlan 平台完善与扩展 v2.0

> 按阶段与维度组织验收检查点。每个检查点对应 spec.md 中的 Requirement 或 Scenario。

## 阶段一：WebGIS 标准能力

### 地图工具栏
- [ ] 地图左侧渲染垂直工具条，含 8 个工具按钮（平移/缩放/测距/测面/坐标拾取/框选/多边形/打印）
- [ ] 每个按钮有图标 + hover tooltip + 激活态高亮
- [ ] 工具栏可折叠隐藏

### 距离测量
- [ ] 点击"测距"按钮（或按 M 键）进入测距模式，光标变十字
- [ ] 连续点击绘制折线，实时显示累计距离（米/公里）
- [ ] 双击结束测量，结果标注保留在地图上
- [ ] 可清除所有测量结果

### 面积测量
- [ ] 点击"测面"按钮进入面积测量模式
- [ ] 点击绘制多边形，实时显示面积（平方米/平方公里）
- [ ] 双击闭合多边形，显示面积与周长

### 坐标拾取
- [ ] 点击"拾取坐标"按钮后，鼠标悬停实时显示 WGS84 + GCJ02 双坐标系
- [ ] 点击地图复制坐标到剪贴板，toast 提示"坐标已复制"

### 空间查询
- [ ] 矩形框选查询：拖动绘制矩形，高亮框内充电站和社区
- [ ] 多边形查询：绘制多边形，筛选落在多边形内的要素
- [ ] 查询结果浮窗列出命中要素数量与列表
- [ ] 列表项可点击飞行定位

### 地图打印
- [ ] 点击"打印"按钮（或按 P 键）弹出打印配置面板
- [ ] 配置项含标题、图例/比例尺/北针开关、PNG/PDF 格式
- [ ] PNG 格式正确导出地图图片
- [ ] PDF 格式嵌入 A4 横版页面，含标题栏与图例

### 图层管理增强
- [ ] 图层面板每项有透明度滑块（0-100%），实时调整图层 opacity
- [ ] 图层项支持拖拽排序，调整图层 z-index

---

## 阶段二：决策分析深化

### 充电站负荷热力图
- [ ] 图层面板新增"负荷热力图"开关
- [ ] 后端 `/api/v1/analysis/heatmap` 正确计算负荷指数
- [ ] 前端用 HeatmapLayer 渲染，颜色从蓝（低）到红（高）
- [ ] 点击充电站显示负荷指数与分级（低/中/高/超载）

### 多方案深度对比
- [ ] 选址面板已保存方案区有"深度对比"按钮（需选中 2 个方案）
- [ ] 后端 `/api/v1/analysis/compare` 返回 6 维度评分
- [ ] 对比矩阵弹窗显示 6 维数值 + 百分制归一化得分
- [ ] 右侧双方案叠加雷达图正确渲染
- [ ] 底部给出"推荐方案"建议及理由

### ROI 估算
- [ ] 选址面板有"ROI 估算"按钮
- [ ] 后端 `/api/v1/analysis/roi` 返回建站成本、年收益、回收周期
- [ ] 弹窗显示成本明细、收益明细、回收周期
- [ ] 参数可调（单桩成本、客单价、需求率），实时重算
- [ ] 保存方案时携带 ROI 数据

### 区域竞争态势
- [ ] 覆盖分析/管理页有"竞争态势"按钮
- [ ] 后端 `/api/v1/analysis/competition` 返回品牌市占率、分布、饱和度、空白市场
- [ ] 报告面板含品牌市占率饼图、行政区堆叠柱状图、饱和度热力图、空白市场列表

### 充电桩缺口预测
- [ ] 有"缺口预测"按钮
- [ ] 后端 `/api/v1/analysis/gap-prediction` 按行政区计算需求与缺口
- [ ] 前端渲染缺口地图（红色缺口大、绿色饱和）
- [ ] 列出 Top 10 缺口最大的行政区

### 方案报告 PDF 导出
- [ ] 已保存方案列表每项有"导出报告"按钮
- [ ] 后端 `/api/v1/export/scheme-pdf` 生成结构化 PDF
- [ ] PDF 含封面/选址依据/指标表/雷达图/ROI/周边站点/地图截图/AI 建议
- [ ] 浏览器正确下载 PDF 文件

## 阶段三：数据大屏与可视化

- [ ] 大屏全屏深色科技风布局，无侧边栏
- [ ] 顶部标题栏含平台名 + 实时时间 + 数据更新时间
- [ ] 左侧 KPI 卡片列显示 5 项核心指标
- [ ] 中央大地图显示全市充电站分布 + 热力图叠加
- [ ] 右侧图表列含 4 项图表（品牌环图/行政区柱图/趋势折线/Top5 盲区）
- [ ] 底部滚动条轮播实时反馈/日志

- [ ] 支持维度组合查询（行政区 × 品牌 × 充电模式 × 运营状态）
- [ ] 展示交叉透视表 + 柱状图/饼图联动
- [ ] 支持导出 CSV 文件

### 公众反馈热力图
- [ ] 图层面板有"反馈热力图"开关
- [ ] 用 HeatmapLayer 渲染反馈点密度热力图

- [ ] **交互完整性**：所有按钮可用、有 loading/empty/error 状态、有快捷键
- [ ] **代码规范性**：注释率 ≥ 30%、组件化拆分、TypeScript 严格类型
- [ ] **文档完整性**：操作手册、设计说明书、源代码整理
- [ ] **产品定位明确**：政府/运营商/车主三角色差异化价值清晰
- [ ] **UI 不空泛**：工具栏整合、状态反馈、紧凑布局、信息密度合理
